# Separador de Contenido de Videos (Karaoke) — Aplicación móvil

Aplicación Android del sistema Separador de Contenido de Videos (Karaoke) potenciado por Machine Learning. Permite consultar y cantar las canciones convertidas en karaoke desde el celular.

## Funcionalidades

- Inicio de sesión con la cuenta del sistema.
- Consulta de las canciones procesadas y de su estado.

## Tecnologías

Flutter y Dart.
